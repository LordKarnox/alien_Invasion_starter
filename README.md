# Starbase Overdrive — Track 1: Custom Game Mechanics

An extension of the Alien Invasion tutorial game, built with Python and pygame.
All project work is on the `track_1_mechanics` branch.

## Milestone 1 — Rapid Prototype of Core Mechanics

- Four-way ship movement inside a lower flight zone
- Hold-to-fire with three firing modes: Single, Spread (3-way), Rapid
- Weapon heat and overheat lockout, with an on-ship heat gauge
- Falling power-ups: **S** Spread, **R** Rapid, **C** Coolant, **SH** Shield
- Base-tutorial fleet, scoring, HUD and Play button isolated until later milestones

## Controls

| Key | Action |
| --- | --- |
| WASD / Arrow keys | Move |
| Space (hold) | Fire |
| 1 / 2 / 3 / 4 | Debug: drop Spread / Rapid / Coolant / Shield above the ship |
| Q / Esc | Quit |

## Running the Game

```
pip install -r requirements.txt
python alien_invasion.py
```
